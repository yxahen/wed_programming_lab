# Лабораторна №4 (варіант 7) — відповіді на питання для самоконтролю

## JavaScript
1. **JavaScript** — мова програмування для веб, що робить сторінки інтерактивними (події, DOM, запити до сервера); працює також на сервері (Node.js).
2. **ECMAScript** — специфікація (стандарт) мови; **JavaScript** — її реалізація в браузерах з додатковими Web API (DOM, fetch тощо).
3. Інлайн (`<script>…</script>`), зовнішній файл (`<script src="script.js"></script>`), атрибути подій (`onclick="…"`, не рекомендується).
4. `let` (змінна з блочною областю), `const` (константа), `var` (застарілий, функціональна область видимості).
5. Примітиви: `string`, `number`, `bigint`, `boolean`, `undefined`, `null`, `symbol`; а також `object` (масиви, функції, дати — теж об'єкти).
6. `undefined` — змінній не присвоєно значення; `null` — значення «порожньо», задане явно.
7. `typeof x` (для масивів — `Array.isArray(x)`, для `null` `typeof` дає `"object"`).
8. Через строге порівняння `===` / `!==` (без приведення типів); `==` приводить типи й може давати неочікувані результати.
9. `умова ? значення_якщо_true : значення_якщо_false`.
10. `if / else if / else`, `switch`, тернарний оператор, `&&`, `||`, `??`.
11. `for` (відома кількість ітерацій), `while` (перевірка умови перед тілом), `do…while` (тіло виконується мінімум раз), `for…of` (елементи ітерованих об'єктів), `for…in` (ключі об'єкта).
12. `break` — повністю виходить із циклу; `continue` — пропускає поточну ітерацію й переходить до наступної.

## React
1. Отримання даних — побічний ефект; `useEffect` виконується після рендеру й не блокує відображення компонента.
2. Порожній масив `[]` — ефект виконується один раз, при монтуванні компонента.
3. Зміна звичайної змінної не викликає перемальовування; зміна стану через `setState` — викликає ререндер, і нові коментарі з'являються на екрані.
4. Зберегти прапорець у `sessionStorage` (на сесію) або `localStorage` (назавжди) при закритті й перевіряти його перед запуском `setTimeout`.
5. Імперативний підхід — ми вручну кажемо, *як* змінити DOM; декларативний — описуємо, *як має виглядати UI* для поточного стану, а React сам оновлює DOM.
